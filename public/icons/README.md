# App icons

Brand artwork from `docs/brand/favicon/` (the Apex mark on Deep Ink Navy), generated by
`docs/brand/logo-exploration/source/build.py` and `rasterise.mjs`. Keep the file names and sizes:

- `favicon.svg`: adapts to the browser theme (navy on light, paper on dark)
- `favicon-32.png`, `../../src/app/favicon.ico` (16 and 32): fallbacks
- `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png`
- `maskable-512.png` is the same artwork as `icon-512.png`: the mark sits inside the central 60%, within the maskable safe zone

If you change an icon, also change `VERSION` in `public/sw.js`, which precaches these files.
